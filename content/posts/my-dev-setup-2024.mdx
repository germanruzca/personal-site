## Hardware

**MacBook Pro M3 Pro, 36GB RAM** — The M-series chips genuinely changed what laptop computing feels like. Compiling large TypeScript codebases or running local Docker environments used to be where laptops fell apart. Not anymore.

**LG UltraFine 4K 27"** — For color accuracy when doing any UI work. Not as beautiful as the Apple Studio Display but a third of the price.

**Keychron Q1 Pro** — Wireless mechanical keyboard with Gateron Brown switches. Quiet enough to use in a coffee shop, tactile enough to feel good. I've been using this for two years and it's the best keyboard I've owned.

## Editor

**VS Code** with a minimal setup:

- Theme: GitHub Dark Default (I tried every theme, this one just works)
- Font: Geist Mono at 14px, 1.6 line height
- Extensions: ESLint, Prettier, GitLens, Error Lens, GitHub Copilot

I tried Neovim for six months. I was productive but I spent more time configuring it than using it. Maybe in another life.

## Terminal

**Ghostty** with zsh and a custom prompt. Fast, GPU-accelerated, feels snappy.

Key tools:
- `fzf` for fuzzy file finding
- `ripgrep` instead of grep
- `zoxide` instead of cd
- `lazygit` for a TUI git interface when I don't want to type git commands

## Browser

**Arc** as my main browser. The command bar and spaces feature genuinely changed how I work. I keep one Space for work and one for personal, with a dedicated one for side projects.

## Apps

- **Linear** for project management (personal projects too)
- **Raycast** for launcher, snippets, clipboard history
- **Obsidian** for notes and writing drafts
- **TablePlus** for databases
- **Proxyman** for HTTP debugging

## The workflow

I work in 90-minute focused blocks. No Slack, no notifications, phone face-down. One task per block. This sounds extreme until you try it and notice that most "urgency" is manufactured.

The biggest productivity unlock isn't a tool — it's deciding what you're not going to work on.
